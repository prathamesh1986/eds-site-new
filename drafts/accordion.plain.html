Frequently Asked Questions

What is Edge Delivery Services?

Edge Delivery Services is Adobe's platform for building fast, content-first websites that score 100 on Lighthouse.

How do I author an accordion?

Create a table with the block name Accordion. Each row is one item: the first cell is the label, the second is the body.

Does it need JavaScript to open and close?

It uses the native HTML <details> element, so expand/collapse works even before JavaScript loads.
